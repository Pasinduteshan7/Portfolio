## 🌐 How to Host on Netlify in 30 Seconds

### Method 1: Netlify Drop (Fastest — 1 Click)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop) and log in.
2. Drag and drop this folder (`d:\PROJECTS\PERSONAL\myself\MY Porfolio`) directly into the drop area.
3. Your portfolio goes live instantly with free SSL!
4. Go to **Site settings → Change site name** to set a custom URL (e.g. `pasindu-teshan.netlify.app`).

### Method 2: GitHub Continuous Deployment (Recommended)
1. Initialize git and push this folder to your GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/Pasinduteshan7/portfolio.git
   git push -u origin main
   ```
2. Log in to [app.netlify.com](https://app.netlify.com), click **Add new site → Import an existing project**.
3. Select your GitHub repository. Netlify will detect `index.html` and deploy automatically on every push!
